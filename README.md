# FP Dashboard

FP Dashboard is a full-stack healthcare opportunity placement platform for Future Physicians. It will provide structured dashboards and internal tooling for students, healthcare partners, staff, and administrators to manage opportunities, applications, placement requests, outreach workflows, matching, and analytics.

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- ESLint
- Prettier
- PostgreSQL later
- Prisma later
- Clerk or Supabase Auth later
- Vercel deployment later

## Local Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

Useful commands:

```bash
npm run lint
npm run build
npm run format:check
```
