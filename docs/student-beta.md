# Student Beta Guide

The student beta is a controlled onboarding period for invited students only.

## Student Checklist

- Complete your profile with school, location, interests, availability, goals, and preferences.
- Upload a resume and review whether parsing completed successfully.
- Browse verified opportunities and use search/filter tools.
- Save or follow an opening-soon opportunity, start preparation, and confirm
  that submission remains unavailable until applications open.
- Use the Tasks page and application workspaces to complete, reopen, or block
  required actions; progress and next action are calculated from those tasks.
- Apply only after reviewing the official source and FP relationship disclosure.
- Add an opportunity found elsewhere as a private, unverified application
  source when it is absent from the FP directory.
- Configure in-app reminders, optional email delivery, quiet hours, timezone,
  and the optional weekly plan from student settings.
- Submit a placement request if the opportunity board does not have the right fit.
- Check notifications for application, interview, onboarding, event, and service-hour updates.
- Use feedback forms on applications and placement requests.

## Beta Expectations

- FP Dashboard is still in beta; wording, workflows, and empty states may change.
- Students should not upload unnecessary sensitive documents.
- Student-added opportunities are private and are never automatically
  published, scraped, verified, or submitted by FP.
- Opening-soon preparation does not mean an application has been submitted.
- Future Physicians staff and partners still make final placement and review decisions.
- Report confusing behavior through the authenticated support page.

The authenticated release checklist is in
`student-authenticated-smoke-checklist.md`. Activities, stories,
recommendations, application answers, interview preparation, and outcomes have
schema foundations only in this release and are not yet student-facing beta
features.
