# Roadmap

Stages 0-50 are complete for the internal beta plan.

## Completed Foundation

- App foundation, Clerk auth, RBAC, Prisma/PostgreSQL, Supabase Storage boundary, notifications, email, audit logs, analytics, AI parsing/matching, semantic search, outreach assistant, background jobs, operational workflows, moderation, imports, public opportunity pages, feedback, embeddings, interviews, service hours, events, sponsorships, security hardening, tests, monitoring, demo mode, and documentation.

## Internal Beta Focus

- Validate role-based workflows with demo and small internal users.
- Tighten copy and empty states from real usage.
- Review legal/privacy language before broader launch.
- Verify deployment environment variables and backups.
- Exercise data import with sanitized sample sheets.
- Review operational automation results before enabling production schedules.
- Use the internal launch, student beta, partner beta, and workflow migration guides to replace old Forms/Sheets processes gradually.

## Likely Next Enhancements

- Better admin/staff dashboards based on beta feedback.
- More robust partner onboarding and verification workflows.
- More event attendance tooling.
- Richer sponsor reporting.
- Expanded test coverage around server actions and role ownership.
- Production-grade privacy/legal review.
- More formal observability runbooks.

## Deferred

- Public application forms.
- Payment processing.
- External calendar or Zoom integration.
- Real-time chat.
- Public sponsor portal.
- Automated accept/reject decisions.
- AI model training.
- pgvector/vector indexes.
